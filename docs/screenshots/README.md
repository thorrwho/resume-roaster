# Screenshots

Drop your own images here using the **same filenames**; the main README picks them up.

| File | What to capture |
| --- | --- |
| `hero.png` | The top of the live site on desktop |
| `roast.png` | Click "Load a sad resume", wait for the toast to react, capture the score and first few roast cards |
| `reveal.png` | Press "Which one was real?" and capture the green card plus the fix box |
| `share-card.png` | The PNG from "Make share card" then "Save image" |
| `mobile.png` | A phone screenshot of a roast |
| `demo.gif` | A 5 to 10 second recording: paste, roast, reveal. Keep it under about 5 MB |

Capture from the live site so the real fonts show. Chrome full-page shot: F12, Ctrl/Cmd+Shift+P, "Capture full size screenshot".
